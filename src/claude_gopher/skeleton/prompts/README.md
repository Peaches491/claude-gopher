# Site prompts

Each `<context>.md` here is appended to gopher's core prompt for that context. Missing files mean
core only.

| File | Used by |
|---|---|
| `all.md` | every agent: repos, build system, tickets, pull requests at this site |
| `gopher.md` | the Gopher agent |
| `project.md` | project agents |
| `resources.md` | resource kinds and URL patterns |
| `archive.md`, `close.md`, `reopen.md` | lifecycle transitions |
| `inbox.md` | framing of injected inbox items |
| `tui-summary.md` | the TUI's summary refresh |
